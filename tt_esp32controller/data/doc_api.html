REST API Dokumentation: TWM Isolation Variac Controller

Basis-URL: http://twm_variac.local/api/
Version: 3.11  |  Datum: 09. Oktober 2025

1. Einleitung

Diese API dient zur Fernsteuerung und Überwachung des TWM Isolation Variac Controllers. Sie ermöglicht das Auslesen des aktuellen Gerätestatus sowie das Senden von Steuerbefehlen über das Netzwerk. Die Kommunikation erfolgt über Standard-HTTP-Anfragen. Alle Daten werden im JSON-Format ausgetauscht.

2. API Endpunkt-Übersicht

3. Endpunkte im Detail

3.1. Gerätestatus abfragen

GET /status

Ruft den vollständigen, aktuellen Zustand des Geräts ab.

Beispiel-Anfrage:

curl http://twm_variac.local/api/status

Antwort: Status Code 200 OK. Body: (Siehe Datenmodell 4.1)

3.2. Soll-Spannung setzen

GET /setpoint

Setzt einen neuen Sollwert für die Ausgangsspannung.

Parameter:

  • voltage [ERF]: Der neue Sollwert als Fliesskommazahl.
curl "http://twm_variac.local/api/setpoint?voltage=120.5"

Antwort: {"status":"success","message":"Setpoint updated"}

3.3. Befehle ausführen

GET /command

Löst vordefinierte Aktionen auf dem Gerät aus.

Parameter:

  • action [ERF]: Der auszuführende Befehl als String.
action-WertBeschreibung
toggle_outputSchaltet den Hauptausgang ein oder aus.
toggle_limitSchaltet die Strombegrenzung ein oder aus.
toggle_regulationSchaltet die aktive Spannungsregelung ein oder aus.
recall_p1Ruft die Spannung des Presets 1 ab.
recall_p2Ruft die Spannung des Presets 2 ab.
recall_p3Ruft die Spannung des Presets 3 ab.
enter_settingsVersetzt das Gerät in den Kalibrierungs-Modus.
curl "http://twm_variac.local/api/command?action=toggle_output"

3.4. Gespeicherte Presets abfragen

GET /presets

Ruft die aktuell für die drei Presets gespeicherten Spannungswerte ab.

curl http://twm_variac.local/api/presets

Antwort: (Siehe Datenmodell 4.2)

3.5. Preset speichern

GET /presets/save

Speichert einen Spannungswert auf einem der drei Preset-Plätze.

Parameter:

  • preset [ERF]: Die Nummer des Presets (1, 2 oder 3).
  • voltage (opt): Der zu speichernde Wert. Ohne Angabe wird die aktuelle Ist-Spannung verwendet.
curl "http://twm_variac.local/api/presets/save?preset=1&voltage=110"

3.6. Kalibrierungswerte abfragen

GET /calibration

Ruft die gespeicherten Minimal- und Maximal-Positionen des Steppers ab.

curl http://twm_variac.local/api/calibration

Antwort: (Siehe Datenmodell 4.3)

3.7. Kalibrierungspunkt speichern

GET /calibration/save

Speichert eine Stepper-Position als Anschlag. Nur im Settings-Modus aktiv.

Parameter:

  • limit [ERF]: "min" oder "max".
  • value (opt): Die Position. Ohne Angabe wird die aktuelle Position verwendet.
curl "http://twm_variac.local/api/calibration/save?limit=min&value=-25"

3.8. Gerät neustarten

GET /reboot

curl http://twm_variac.local/api/reboot

Antwort: Rebooting in 200ms...

3.9. Log-Datei abrufen

GET /log

Parameter:

  • old: "true" für system.log.old
  • download: "true" für Download-Header
curl "http://twm_variac.local/api/log?download=true"

3.10. Dateien auflisten

GET /files

curl http://twm_variac.local/api/files

3.11. Datei löschen

GET /files/delete

Parameter: filename (erforderlich, Pfad beginnend mit /).

curl "http://twm_variac.local/api/files/delete?filename=/system.log.old"

3.12. Konfiguration auslesen

GET /config

curl http://twm_variac.local/api/config

3.13. Konfiguration schreiben

POST /config

Erwartet valides JSON im Body. Beispiel für Preset-Update:

curl -X POST -H "Content-Type: application/json" -d "{\"presets\":{\"p1\":55}}" http://twm_variac.local/api/config

5. Fehlerbehandlung und Statuscodes

Die API verwendet Standard-HTTP-Statuscodes.

5.1. Erfolgreiche Anfragen

Code: 200 OK

Anfrage erfolgreich. Body enthält Daten oder Erfolgs-JSON:

{ "status": "success", "message": "Command executed" }

5.2. Fehlerhafte Anfragen

Code: 400 Bad Request

Tritt auf bei fehlenden Parametern oder ungültigen Werten.

{ "status": "error", "message": "Missing 'action' parameter" }

5.3. Nicht gefundene Ressource

Code: 404 Not Found

{ "status": "error", "message": "Endpoint not found" }

5.4. Dienst nicht verfügbar

Code: 503 Service Unavailable

Hardware nicht bereit (hardwareInitialized ist false).

{ "status": "error", "message": "Hardware not ready" }
